# 개발 규칙

## 기본 원칙

- Spring Boot와 Spring MVC `@RestController`를 사용합니다.
- JPA/Lombok을 사용하지 않습니다.
- DB 접근은 `ConnectionManager`, `JDBCUtil`, 순수 JDBC를 사용합니다.

## 표준 JSON 응답

성공 응답:

```json
{
  "success": true,
  "data": {}
}
```

실패 응답:

```json
{
  "success": false,
  "error": {
    "code": "ERROR_CODE",
    "detail": "에러 설명"
  }
}
```

## 컨트롤러 개발 규칙

컨트롤러는 `@RestController`를 사용합니다.

```java
@RestController
public class MeetupController {
    @GetMapping("/api/meetups/{meetupId}")
    public ApiResponse<MeetupResponse> findMeetup(@PathVariable Long meetupId) {
        return ApiResponse.success(...);
    }
}
```

JSON 요청 body는 `@RequestBody`로 DTO에 매핑합니다.

```java
@PostMapping("/api/members/login")
public ApiResponse<MemberResponse> login(
        @RequestBody MemberLoginRequest request,
        HttpServletRequest httpRequest
) {
    MemberResponse member = memberService.login(request);
    SessionUtil.login(httpRequest, member.memberId());
    return ApiResponse.success(member);
}
```

DTO는 `record` 사용을 우선합니다.

```java
public record MemberLoginRequest(String email, String password) {
}
```

## 에러 코드 개발 규칙

도메인별 에러 코드는 `dbp.backend.common.exception.code.ErrorCode`를 구현하는 enum으로 만듭니다.

```java
public enum MemberErrorCode implements ErrorCode {
    MEMBER_NOT_FOUND(HttpServletResponse.SC_NOT_FOUND, "회원을 찾을 수 없습니다.");

    private final int statusCode;
    private final String detail;

    MemberErrorCode(int statusCode, String detail) {
        this.statusCode = statusCode;
        this.detail = detail;
    }

    public int getStatusCode() {
        return statusCode;
    }

    public String getDetail() {
        return detail;
    }
}
```

응답의 `error.code`는 enum 상수명인 `MEMBER_NOT_FOUND`가 사용됩니다.

## 예외 처리 규칙

API에서 에러를 발생시켜야 하면 `ApiException`을 사용합니다.

```java
throw new ApiException(CommonErrorCode.BAD_REQUEST);
throw new ApiException(CommonErrorCode.UNAUTHORIZED);
throw new ApiException(MemberErrorCode.MEMBER_NOT_FOUND);
```

DB 처리 중 발생한 `SQLException`은 `DatabaseException`으로 감싸서 던집니다.

```java
try (Connection conn = ConnectionManager.getConnection()) {
    return JDBCUtil.executeQuery(conn, sql, mapper, params);
} catch (SQLException e) {
    throw new DatabaseException(e);
}
```

`GlobalExceptionHandler`가 `ApiException`을 잡아서 표준 JSON 에러 응답으로 변환합니다.

```json
{
  "success": false,
  "error": {
    "code": "BAD_REQUEST",
    "detail": "잘못된 요청입니다."
  }
}
```

## JDBC 개발 규칙

DB 연결은 `ConnectionManager`를 사용하고, `JDBCUtil`에는 항상 `Connection`을 명시적으로 넘깁니다.
DB 설정은 프로젝트 루트의 `.env` 파일 또는 시스템 환경변수로 관리합니다.
시스템 프로퍼티, 시스템 환경변수, `.env` 순서로 값을 읽습니다.
`ConnectionManager` 내부에서는 Apache Commons DBCP2 커넥션 풀을 사용합니다.
DAO에서는 커넥션 풀 구현을 직접 다루지 않고 `ConnectionManager.getConnection()`만 사용합니다.

```java
try (Connection conn = ConnectionManager.getConnection()) {
    int count = JDBCUtil.executeUpdate(
            conn,
            "INSERT INTO MEMBER (EMAIL, PASSWORD) VALUES (?, ?)",
            email,
            password
    );
}
```

DAO에서는 SQL 문자열에 사용자 입력을 직접 이어 붙이지 않습니다.

반복적인 파라미터 바인딩과 SQL 실행은 `JDBCUtil`을 사용합니다.

조회 결과는 `ResultSetMapper` 콜백에서 변환합니다.

```java
try (Connection conn = ConnectionManager.getConnection()) {
    Member member = JDBCUtil.executeQuery(
            conn,
            "SELECT MEMBER_ID, EMAIL FROM MEMBER WHERE MEMBER_ID = ?",
            rs -> {
                if (!rs.next()) {
                    return null;
                }
                return new Member(rs.getLong("MEMBER_ID"), rs.getString("EMAIL"));
            },
            memberId
    );
}
```

트랜잭션이 필요한 경우에도 같은 `Connection`을 넘겨 여러 SQL을 묶습니다.

```java
try (Connection conn = ConnectionManager.getConnection()) {
    conn.setAutoCommit(false);
    JDBCUtil.executeUpdate(conn, sql1, param1);
    JDBCUtil.executeUpdate(conn, sql2, param2);
    conn.commit();
} catch (SQLException e) {
    // rollback 처리
}
```

## 세션 개발 규칙

로그인 성공 시 `SessionUtil`에 로그인 회원 ID를 저장합니다.

```java
SessionUtil.login(request, memberId);
```

로그인 여부와 현재 로그인 회원 ID는 `SessionUtil`로 확인합니다.

```java
if (!SessionUtil.isLoggedIn(request)) {
    throw new ApiException(CommonErrorCode.UNAUTHORIZED);
}

Long loginMemberId = SessionUtil.getLoginMemberId(request);
```

로그아웃은 세션을 무효화합니다.

```java
SessionUtil.logout(request);
return ApiResponse.success(null);
```

React에서 세션 쿠키를 주고받는 요청에는 `credentials: "include"`를 넣습니다.

```javascript
fetch("http://localhost:8080/api/members/me", {
  credentials: "include"
});
```
